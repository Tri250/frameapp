# 发布检查表

[English](release-checklist.md) | [简体中文](release-checklist.zh-CN.md)

供开发者在分发前验收。填写 [发布材料](distribution/README.md) 后验收。

版本／构建号： · 标签／完整 SHA： · 负责人／日期：

- [ ] 发布提交的必需 CI 通过，审查讨论已解决。
- [ ] 版本及构建号递增，发布说明列出行为变化和限制。
- [ ] Android／iOS 真机证据记录设备、系统、验证人及结果。
- [ ] 检查主体点选、移动、跟丢／重选、低光、晃动和快速移镜。
- [ ] 检查主快门／直接拍照、前后摄、裁剪／方向及相册保存。
- [ ] 检查拒绝权限／重试、空间不足和保存失败重试。
- [ ] 检查同意前不启动、撤回、后台恢复与政策页返回。
- [ ] 填写自己的运营者／联系信息，验证本地政策显示与页面跳转。
- [ ] 使用独立发布者自己的正式签名，产物不含 debug 签名或凭据。
- [ ] 构建对应验收 SHA，记录哈希、版本和签名标识。
- [ ] 保留 MIT 与第三方声明，新增素材有分发授权。
- [ ] 完成内测、商店资料及必要的隐私申报。
- [ ] 保留作者／共同作者，贡献者展示已取得同意。
- [ ] 记录不可移动的发布标签、发布负责人和后续修复安排。

## 首次公开前

- [ ] 检查跟踪文件与 Git 历史中的密钥、私人资料和签名文件。
- [ ] 已填写的商店／软著材料与构建产物不进入 Git；空白模板可公开。
- [ ] 核对源码／素材许可、开发者 README 及双语指南。
- [ ] 启用并实测 GitHub 规则与必需检查，见 [协作说明](community-governance.zh-CN.md)。
