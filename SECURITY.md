# 安全问题 / Security

涉及照片泄露、权限绕过、凭据等安全问题，优先使用仓库 Security 页的 **Report a vulnerability**（若已启用）。若未提供私密报告入口，只开 Issue 请求维护者提供私密渠道，不公开漏洞细节、私人照片或密钥。私密报告请附受影响版本、最小复现与脱敏证据；普通问题直接使用 Issue。

For photo disclosure, permission bypasses, credentials or other security vulnerabilities, use **Report a vulnerability** on the repository Security page if enabled. Otherwise, open an Issue requesting a private channel without disclosing exploit details, private photos or keys. Include the affected version, minimal reproduction and redacted evidence in the private report. Ordinary bugs belong in Issues.

维护范围为 `main`；独立分发版本请联系实际发布者。不承诺固定响应时间或漏洞奖励。

The supported code is `main`; contact the distributor for independent builds. No fixed response time or bounty is promised.
