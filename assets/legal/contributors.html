贡献如何被认可

  1. 工作有可查证的 PR 或 Issue 记录，代码已经合入，其他成果已被采纳。
  2. 维护者根据实际影响确认 1、3、5 或 8 分。同一项工作只计一次，协作完成时按约定分摊。
  3. 榜单展示累计贡献，附带近 90 天的贡献；相同累计分并列。被撤回的成果不再计分。
  4. 至少有一项有效贡献，并同意展示昵称和 GitHub 身份后，才会进入展示名单。代码行数、Star 和无效提交不计分。

贡献分是社区认可记录，不代表收入、股权或报酬。展示是可选的，未上榜不会影响你的代码署名。

确认记录，或调整展示

发现归属遗漏、分值有异议，或希望修改昵称、退出展示？请通过 仓库 Issue 提交公开记录；涉及私人资料时先申请私下联系渠道。
